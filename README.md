## 🌟 Overview

**Elevate** is a commercial-grade, multi-tenant AI productivity SaaS built for high-performing professionals and cyber athletes. It bridges the gap between **physical athletic tracking** (Gym, Sprinting, Badminton) and **cognitive deep-work management**, wrapped in a hyper-interactive, glassmorphic UI with dynamic light/dark modes.

---

## 🔥 Key Features

### 🎨 1. Vivid Dual Theme Engine & Micro-Animations
* **Dark Cyberpunk Mode**: Deep cosmic backgrounds (`#030712`) with glowing neon accents, pulsing ambient radial gradients, and flame streak particle effects.
* **Light Clean Mode**: Ultra-crisp, high-contrast white aesthetic with slate typography (`#0f172a`) and royal indigo accents (`#4f46e5`).
* **Interactive 3D Cards**: Expandable athletic matrix cards, micro-animated streak indicators, and smooth hover states.

### 🤖 2. Context-Grounded AI Coach (Voice & Action Engine)
* **Real-Time Database Grounding**: Automatically injects live task backlogs, level/XP metrics, strain, and recovery data into the AI context.
* **Autonomous Tool Calling**: Tells the AI to schedule a workout or sprint, and it automatically creates the task in your database.
* **Persona Adaptation**: Switch dynamically between *Tough Love / Military*, *Scientific Bio-Hacker*, and *Empathetic Mentor* coaching personas.
* **Dynamic Offline Engine**: Fallback natural language understanding that parses user intent even without an API key configured.

### ⌚ 3. Bluetooth BLE & Wi-Fi Wearable Discovery Hub
* Native **Web Bluetooth API** pairing integration.
* Connect Apple Watch Ultra, Garmin, Polar H10, and Fitbit devices to stream heart rate (BPM), HRV (ms), and active calorie burn.

### 🎮 4. Gamification & Global Boss Raid
* **RPG XP & Leveling System**: Earn XP by completing tasks and logging habits to unlock badges.
* **Global Community Boss Raid**: Shared health pool (`Procrastination Behemoth`) attacked whenever users log completed tasks.
* **Top 0.1% Global Leaderboard**: Live competitive ranking across users.

### 📊 5. Stock-Style Analytics & Executive Reporting
* Live **Ghost Pace Race Charts** comparing current daily focus vs. past records.
* Automated **Executive Performance Briefing Generator** (exportable report).
* Interactive 3D Habit Matrix for daily streak tracking.

## 🛠️ Tech Stack

* **Frontend**: Streamlit, Custom CSS3 Keyframes, HTML5 Glassmorphism
* **Analytics**: Plotly Express & Plotly Graph Objects
* **Persistence**: SQLite with WAL (Write-Ahead Logging) Mode & Multi-Tenant Schema Migrations
* **AI & NLP**: OpenAI API (`gpt-4o-mini`), Function Calling (Tools), Intent Parsing Engine
* **Biometrics**: Browser Web Bluetooth (BLE) API
* **Voice**: Streamlit Mic Recorder & Speech-to-Text
